# Подбор вин: демо-приложение

Приложение на Streamlit для модели, которая по физико-химическому анализу вина
предсказывает, стоит ли включать его в подборку сервиса по подписке.

## Запуск локально

Требуется Python 3.12.

```bash
pip install -r requirements.txt
streamlit run app.py
```

После запуска приложение откроется в браузере (обычно http://localhost:8501).

## Что внутри

- `app.py` : код приложения;
- `model.joblib` : обученный пайплайн (StandardScaler + логистическая регрессия);
- `config.json` : порог отбора по умолчанию (0.241, подобран на валидации
  как максимальный precision при recall не ниже 0.7);
- `test.csv` : тестовая выборка, на которой считаются модельные метрики.

## Вкладки

1. **Оценка вина** : ввод 12 признаков вина, вероятность и решение при текущем пороге.
2. **Модельные метрики** : матрица ошибок, precision, recall, F1, ROC- и PR-кривые
   с точкой текущего порога; порог меняется слайдером в сайдбаре.
3. **Пакетное предсказание** : загрузка CSV с признаками вин, таблица вероятностей
   и решений, скачивание результата.
4. **Что выучила модель** : столбчатая диаграмма коэффициентов.

## Деплой на Streamlit Community Cloud

1. Залить папку `wine_app/` в репозиторий на GitHub.
2. На https://share.streamlit.io выбрать репозиторий, ветку и файл `app.py`.
3. Нажать Deploy.
